Lemon Tahini Dressing-IF

Tags: Vegan, Gluten-Free, Dairy-Free, Nut-Free

Source: Insight Retreat Center

Scale recipe: or ×

Equipment

  • Vitamix container (use two, one per batch, if doubling)

Ingredients for ONE Vitamix container (do this twice if making extra)

Preparation

  1. If needed, double the recipe using two Vitamix containers.
  2. Using electric juicer, juice the lemons.
  3. Wash parsley and cut off stems (some of the upper stems are OK).
  4. Add all ingredients in the order above to the Vitamix container. Repeat if making two batches in a second Vitamix container.
  5. Fill two small pitchers with each Vitamix container of salad dressing made.
